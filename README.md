# Colora

Colora is an Apple platform application project focused on working with colors. The repository contains the app target, custom fonts, and unit/UI test targets.

## Project structure

- `Colora/` — application source
- `ColoraTests/` — unit tests
- `ColoraUITests/` — UI tests
- `Fonts/` — bundled fonts
- `Colora.xcodeproj/` — Xcode project

## Run locally

Open `Colora.xcodeproj` in Xcode on macOS, select a simulator or device, and run with `⌘R`.

## Testing

Run the unit and UI tests from Xcode with `⌘U`.
